# Бесплатная озвучка: иврит и русский

Подготовлен клиент `edge-tts==7.3.1` для проверки нейроголосов Microsoft без покупки API-ключа:

| Роль | Голос | Язык |
| --- | --- | --- |
| Девушка | `he-IL-HilaNeural` | Иврит |
| Охранник | `he-IL-AvriNeural` | Иврит |
| «пиздец котёнку» | `ru-RU-SvetlanaNeural` | Русский |

Это синтез речи, не запись актёров и не специальная модель пения. Выбор этих голосов требует проверки по коротким образцам. Их присутствие проверяется по актуальному каталогу сервиса при запуске; в текущей среде каталог пока недоступен.

## Текущее состояние

Клиент установлен в `/workspace/.tools/edge-tts/python`. Скрипт `scripts/generate-free-voices.py` подготовлен. Реальный запуск `--catalog` остановился на сетевом прокси: `403 Forbidden`. Образцы Microsoft ещё не созданы, и готовый ролик пока не переозвучен.

Доступ к `speech.platform.bing.com` добавлен в черновик настроек среды. Чтобы выполнить сетевую проверку, нужно сохранить изменения в настройках среды и опубликовать среду. Сохранение черновика само по себе текущую сетевую политику не меняет.

## Проверка и образцы

```sh
cd /workspace/MA-SiSMA/video
python scripts/generate-free-voices.py --catalog
python scripts/generate-free-voices.py
```

После успешного обращения к сервису в `out/native-voice-auditions` появятся:

- `female-hebrew-with-pauses.wav` — три цельные фразы «אני חמודה» с паузами, без изменения высоты или ускорения речи;
- `male-guard-hebrew.mp3` — «מה הסיסמה?»;
- `female-russian-password.mp3` — «пиздец котёнку»;
- `manifest.json` — голоса, тексты и фактические длительности.

Скрипт использует существующий HTTPS-прокси и дополняет проверку сертификатов доверенными корнями среды, сохраняя проверку TLS. Данные генерируются отдельно от `public/audio`. До прослушивания образцов они не подменяют текущую озвучку.

Для установки клиента в другой подготовленной среде:

```sh
python -m pip install --target /workspace/.tools/edge-tts/python -r scripts/requirements-free-voices.txt
```
