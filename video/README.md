# אני חמודה — מה הסיסמה?

Комедийный мультфильм по сценарию пользователя: **77 секунд, 1080×1920, 30 кадров/с**. Яркая рисованная героиня создана с опорой на фотографию. Все реплики — на иврите, кроме точного русского пароля **«пиздец котёнку»**.

[Скачать готовый MP4](exports/ani-hamuda.mp4)

У героини огромная плетёная связка с девятью ключами, котиком, помпоном, сердцем, звездой, глазом и автомобильным пультом. Машина обгоняет её слева. После разговора с охранником она идёт к собственному кабинету, поёт с паузами, выбирает ключ, открывает дверь и заходит. Последний крик слышен уже из кабинета: **«אוף! אני עייפה!»**.

## Таймлайн

Все значения ниже — абсолютное время от начала ролика.

| Время | Действие и звук |
| --- | --- |
| 00:00–00:13 | Утро и машина. Пение начинается в 00:01.00: три раза «אני חמודה». Реплика о ключах — с 00:08.40. |
| 00:13–00:32 | Поездка и обгон слева. Возмущённая реплика — с 00:17.20. С 00:24.20 снова три раза «אני חמודה», затем 1,5 секунды «לה־לה־לה». |
| 00:32–01:01 | Домофон. Вопрос охранника — 00:33.10. Шесть повторов песни — с 00:36.00 до 00:48.30. Крик охранника — 00:49.50. Русский пароль — 00:53.00. Разрешение войти — 00:56.00. |
| 01:01–01:17 | Собственный кабинет. С 01:01.20: «אני חמודה», пауза, «אני חמודה», пауза, «אני עייפה», пауза. Выбор ключа — 01:07.50–01:09.50. Дверь открывается в 01:09.50–01:12.00; героиня заходит в 01:12.00–01:13.50. Крик изнутри — с 01:13.60. |

Каждая певческая фраза длится **1,30 секунды**, после неё идёт **0,75 секунды настоящей паузы в вокале**. Один повтор с паузой занимает 2,05 секунды. Фоновое сопровождение остаётся тихим и во время пауз.

## Посмотреть и редактировать

Готовый MP4 воспроизводится без установки Remotion, Python или речевых моделей. Для редактирования в подготовленной среде:

```sh
cd /workspace/MA-SiSMA/video
npm run dev -- --no-open --port 3333
```

В Remotion Studio выберите `AniHamuda`. Сцены `Morning`, `Road`, `Intercom`, `Final` доступны отдельно. Звук включается после нажатия Play. Установленные зависимости уже находятся в `node_modules`; запуск проекта не требует загрузки речевой модели.

При необходимости переустановки из полного подготовленного npm-кеша:

```sh
npm_config_cache=/workspace/.cache/npm npm ci --offline
```

Для автономного HTML-просмотра соберите файл и затем откройте его в браузере:

```sh
npm run preview:build
```

Результат — `out/ani-hamuda-preview.html`: изображения, голоса, сопровождение и шрифты встроены. После изменений файл нужно собрать заново.

## Материалы и голоса

- `script.he.md` — сценарий с абсолютным временем реплик.
- `src/captions.json` — субтитры с локальным временем каждой сцены; паузы между певческими фразами сохранены.
- `public/images` — героиня в полный рост и три выражения лица.
- `public/audio` — готовые WAV и манифесты генерации. Все материалы для воспроизведения входят в репозиторий.
- Женский голос — **локальная нейросеть Kokoro ONNX, `bf_emma`**. Цельные фонемные фразы положены на новую мягкую мелодию в низком диапазоне **174,61–220 Гц**. Голос синтетический, голос женщины с фотографии не клонировался. Kokoro не является моделью с родным ивритом, поэтому возможен акцент.
- Мужской голос охранника — ранее созданный локальный **eSpeak NG**, обработанный как звук домофона. Готовые реплики охранника сохраняются при повторной генерации женского голоса.

## Повторная генерация звука без сети

В подготовленной среде модель и Python-зависимости уже кешированы в `/workspace/.tools/kokoro`. `scripts/generate-audio.py` использует только существующие локальные файлы и не скачивает данные автоматически. При отсутствии модели он завершится с понятной ошибкой.

```sh
cd /workspace/MA-SiSMA/video
KOKORO_ROOT=/workspace/.tools/kokoro python3 scripts/generate-audio.py
python3 scripts/generate-ambience.py
```

Для женского голоса нужны `kokoro-onnx==0.6.1`, ONNX Runtime, NumPy, SoundFile, `praat-parselmouth==0.4.7` и FFmpeg с фильтром `rubberband`. Модельный кеш должен содержать `kokoro-v1.0.onnx`, `voices-v1.0.bin` и установленные зависимости в подкаталоге `python`. eSpeak для генерации женского голоса не нужен. Сценарий сохраняет уже имеющиеся WAV охранника.

`scripts/generate-ambience.py` синтезирует 77 секунд тихого сопровождения и звуки ключей, автомобиля, домофона и двери локально; ему нужны Python и NumPy.

Веса модели размером около 311 МБ в репозиторий не включены. Они нужны только для изменения голосов. Справочный источник файлов модели: [Kokoro ONNX model-files-v1.1](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.1).

## Проверка и экспорт

```sh
cd /workspace/MA-SiSMA/video
npm run lint
npm run build
./node_modules/.bin/remotion render src/index.ts AniHamuda out/ani-hamuda-v2.mp4 --browser-executable=/usr/bin/chromium --concurrency=4
```

Экспорт использует установленный локальный Chromium. Для сохранения готового файла рядом с исходниками:

```sh
mkdir -p exports
cp out/ani-hamuda-v2.mp4 exports/ani-hamuda.mp4
```

Каталог `out` игнорируется Git; итоговый `exports/ani-hamuda.mp4` входит в репозиторий.
