# Стили для видео

80 описаний визуальных стилей из архива «Скачать стили.zip». Исходные имена и содержимое файлов сохранены без изменений.

Каждый файл содержит описание стиля, шаблон задания и примеры кода анимации. Чтобы использовать стиль, откройте соответствующий файл и подставьте тему или сценарий в раздел `MY CONTENT`.
